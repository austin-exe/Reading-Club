Project Overview

The Reading Club is a premium desktop application designed for libraries, book clubs, and personal archives. It replaces outdated spreadsheets with a powerful, automated database system wrapped in a stunning Noir & Taupe interface.

Developed with a focus on User Experience (UX), it features seamless Borrow/Return logic, automatic status tracking, and a comprehensive audit history. Under the hood, it leverages a robust REST API built with Flask, ensuring data integrity and speed.

Key Features

Smart Inventory

A beautiful grid view of all Books, Films, and Magazines with automatic ID sequencing and striped rows for readability.

Borrow & Return

Effortless circulation management. Check items out to members and return them with a single click. Status updates instantly.

Instant Search

Find any item in milliseconds. Filter your collection by Title, Creator, or Category using the integrated search engine.

Audit Trails

Maintain complete accountability with a permanent history log of every transaction, edit, and deletion.

Installation & Setup

1

Get the Code

Download the source code ZIP using the button above, or clone the repository via terminal.

git clone https://github.com/austin-exe/Reading-Club.git
2

Install Requirements

Navigate to the project folder and install the necessary Python libraries.

pip install flask requests
3

Initialize Server

Start the backend API first. This will automatically generate the database.

python server.py
4

Launch Application

Open a new terminal window and run the frontend interface.

python app.py

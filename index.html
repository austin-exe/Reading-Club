Project Overview

The Reading Club is a premium desktop application designed for libraries, book clubs, and personal archives. It replaces outdated spreadsheets with a powerful, automated database system wrapped in a stunning Noir & Taupe interface.

Developed with a focus on User Experience (UX), it features seamless Borrow/Return logic, automatic status tracking, and a comprehensive audit history. Under the hood, it leverages a robust REST API built with Flask, ensuring data integrity and speed.

Key Features Showcase

Smart Inventory Grid

A beautiful, organized view of your entire collection. Features automatic ID sequencing, clear categorization (Books, Films, Magazines), and live status updates. The striped rows and Noir theme ensure maximum readability.

Actionable Sidebar

Manage items effortlessly. Selecting an item brings up a detailed sidebar with a synopsis and large, clear action buttons. Check items out to members or mark them returned with a single click.

Instant Search

Locate any item in milliseconds. The integrated search engine filters your collection dynamically by Title, Creator, or Genre as you type, making collection navigation instantaneous.

Audit History Log

Maintain complete accountability. Access a permanent, time-stamped history log for any item to see exactly who borrowed it, when it was returned, and track circulation trends over time.

How to Play

  • Wait exactly 6-7 seconds.
  • Remove item before it burns!

Controls

  • Left Click + Hold: Pick Up

Installation & Setup

1

Get the Code

Download the source code ZIP using the button above, or clone the repository via terminal.

git clone https://github.com/austin-exe/Reading-Club.git
2

Install Requirements

Navigate to the project folder and install the necessary Python libraries.

pip install flask requests
3

Initialize Server

Start the backend API first. This will automatically generate the database.

python server.py
4

Launch Application

Open a new terminal window and run the frontend interface.

python app.py
